# Calculadora de Nuevos Negocios
Web app para estimar los ingresos anuales de nuevos negocios y compartir ideas con equipos de trabajo. Permite personalizar el modelo de negocio según la cantidad y tipo de propuestas de valor, así como el número de segmentos de clientes. Finalmente, la app permite guardar toda la información ingresada en formato PDF.

La web app, que está disponible en [este link](https://share.gemini.google/knthkIcp3yJj), fue desarrollada con la herramienta Canvas de Gemini usando el método "vibe coding".
